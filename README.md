Interview Helper Chatbot using GENAI | Python, Gemini API, Streamlit, Prompt Engineering, LLMs  
AI-powered chatbot for generating technical interview questions 
● LLM Integration: Leveraged Google's Generative AI (Gemini API) to generate customized interview questions 
and answers based on job titles. 
● Adaptive Prompting: Designed prompts to dynamically generate relevant technical questions based on 
user-entered job roles. 
● Streamlit UI Interface: Developed an interactive, user-friendly web app with Streamlit, enabling seamless input 
for job titles and real-time Q&A display. 
● Secure API Management: Integrated Python’s dotenv for secure API key configuration, ensuring safe access and 
environment management. 
● Enhanced User Experience: Intuitive controls for streamlined navigation and user interaction.
